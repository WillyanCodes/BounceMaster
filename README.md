# 💼 CRM Simples

Um sistema web de gerenciamento de clientes (CRM) 100% funcional, desenvolvido com **HTML, CSS e JavaScript puro**, ideal para demonstração de portfólio e projetos profissionais.

---

## 🧩 Funcionalidades

✅ Adicionar, editar e remover clientes  
✅ Pesquisar por nome ou empresa  
✅ Ordenar colunas (nome, email, empresa etc.)  
✅ Exportar lista de clientes para arquivo CSV  
✅ Armazenamento local (os dados permanecem após atualizar a página)  
✅ Design responsivo e interface moderna  

---

## 🖥️ Tecnologias utilizadas

- **HTML5** → estrutura do sistema  
- **CSS3** → design e responsividade  
- **JavaScript (ES6)** → lógica e interatividade  
- **LocalStorage** → persistência de dados no navegador  

---

## 🧠 Como usar

1. Abra o projeto hospedado no GitHub Pages ou localmente no navegador.  
2. Preencha o formulário com os dados do cliente.  
3. Clique em **“Adicionar Cliente”**.  
4. Use o campo de **pesquisa** para filtrar rapidamente por nome ou empresa.  
5. Clique em **Editar** ou **Excluir** conforme necessário.  
6. Clique em **Exportar CSV** para baixar sua lista.
